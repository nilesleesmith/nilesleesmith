# About Me

I'm a software developer focused on full-stack web development and building web applications.

My background in finance, operations, and automation shaped the kinds of problems I like to solve with software. I have seen how repetitive work, complicated processes, and inefficient workflows create unnecessary friction, and that experience continues to influence what I build.

I build practical tools that automate repetitive work, simplify complicated tasks, and make processes easier to understand and manage. I'm especially interested in software that saves time and removes unnecessary work.

## How I Approach Development

I start with the problem, not the technology. Before choosing tools or architecture, I work to understand what the software needs to do, who it is for, and which requirements and constraints actually matter.

I prefer straightforward solutions over unnecessary complexity. Simple does not mean writing the fewest lines of code. It means building a complete solution without adding abstractions, dependencies, features, or architecture that do not serve a clear purpose.

I build software to be useful and understandable. The experience of the person using it matters, and so does the experience of the developer who needs to read, debug, maintain, or change it later.
